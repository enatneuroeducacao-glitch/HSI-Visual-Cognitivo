# HSI Visual Cognitivo

Plataforma independente do ENAT para exercícios visuais experimentais em seis eixos:
- Raciocínio lógico
- Atenção seletiva
- Percepção de padrões
- Antecipação de situações
- Percepção de riscos no trânsito
- Tomada de decisão

## Estado da migração

Este repositório foi criado para receber o código-fonte recuperado do AppDeploy. A versão publicada original permanece separada e não é alterada por este repositório.

## Stack recuperada
- React 19
- Vite 8
- TypeScript
- CSS responsivo

## Próximos passos
1. Remover a dependência de `@appdeploy/client` e `@appdeploy/sdk`.
2. Implementar autenticação e persistência independentes.
3. Implementar uma API de orientação IA independente, por provedor configurável.
4. Validar relatórios e fluxos de usuário.

## Nota metodológica
Os resultados são descritivos e experimentais. Não constituem diagnóstico, laudo, avaliação de aptidão para dirigir ou índice HSI validado; não substituem o HSI-DOTH-P.
